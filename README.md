# Guess the Number

## Описание проекта

Проект решает задачу угадывания случайного целого числа от 1 до 100.
Для поиска используется алгоритм бинарного поиска.
На каждой итерации диапазон возможных значений сокращается в два раза.

## Результат

Алгоритм находит загаданное число максимум за 7 попыток.
Среднее количество попыток значительно меньше 20.

## Используемые технологии

- Python
- NumPy
- Jupyter Notebook

## Запуск проекта

1. Склонируйте репозиторий.
2. Установите необходимые библиотеки:
   pip install -r requirements.txt
3. Откройте guess_the_number.ipynb в Jupyter Notebook.
4. Запустите все ячейки.
